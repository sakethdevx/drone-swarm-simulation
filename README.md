# Drone Swarm Simulation

A 3D simulation environment for visualizing and managing a drone swarm. Built with React, TypeScript, Vite, and Three.js.

## Features

- **3D Visualization:** Real-time 3D rendering of the environment, drones, and paths.
- **Swarm Control & Playback:** Start, pause, and control simulation timeline and playback speed.
- **Waypoint Editor:** Define and modify drone waypoints dynamically.
- **Obstacle Management:** Add, select, resize, and remove obstacles (spheres, boxes) in the environment. The drones must navigate around them.
- **Debug Visuals:** Toggle visualization helpers to inspect the 3D scene, obstacle radii, and paths.

## Technologies

- React + TypeScript
- Vite
- Three.js / React Three Fiber
- Zustand (State Management)
- Tailwind CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
